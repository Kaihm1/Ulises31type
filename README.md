# ULISES 31: ODISEA R-TYPE

Prototipo jugable de *shoot 'em up* horizontal estilo *R-Type* inspirado en **Ulises 31**, compatible con **PC (teclado / mando)** y **móviles / tablets (controles táctiles)**.

## Episodios incluidos
- **Episodio 01: El Cíclope — La maldición de los dioses** (Templo del Cíclope + Jefe Cíclope Mecánico).
- **Episodio 02: El Planeta Perdido — Zotra** (Cavernas de Cristal + Centinela de Zotra + Jefe Hechicera de Cristal).

## Controles
- **PC (Teclado):** `WASD` / Flechas (mover), `Z` / `Espacio` (disparo y BEAM cargado), `C` (autofire), `X` / `Shift` (Nono-Pod), `V` / `E` (separar 3 módulos), `1` / `2` (elegir fase), `P` (pausa), `M` (audio).
- **Mando / Gamepad:** Stick o cruceta, `A` (disparo/BEAM), `B`/`RB` (Nono-Pod), `Y`/`LB` (3 módulos), `X`/`RT` (autofire), `Start` (pausa).
- **Móvil / Tablet:** Joystick virtual + botones táctiles (`FIRE/BEAM`, `AUTO`, `POD`, `3 MOD`).
